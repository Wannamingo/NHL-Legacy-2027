# NHL Legacy 2027 для Android

Неофициальный порт NHL Legacy Edition для Android ARM64. Релиз `v1.0.1` содержит лаунчер NHL Legacy 2027, Vulkan-рендер, экранное управление и импорт игровых файлов из собственного Xbox 360 ISO.

## Установка

1. Установите `NHL-Legacy-2027.apk` на устройство Android ARM64.
2. Скопируйте на устройство собственный ISO **NHL Legacy Edition (USA, Europe) (En,Fr,De,Sv,Fi,Ru,Cs)**. Проверенная версия Redump имеет размер **8 738 846 720 байт**.
3. В лаунчере нажмите **«Импорт ISO»** и выберите файл. Приложение извлечёт необходимые 20 файлов (около **6,3 ГБ**) в своё хранилище и проверит их размеры и SHA-256. Для установки необходимо свободное место под извлечённые файлы; после успешного импорта образ можно убрать с устройства.
4. Запустите игру. По умолчанию выбран системный видеодрайвер (Lenovo Y700 8gen3) и показана полная арена.

ZIP используется отдельно для обновлений составов и дополнительных Vulkan-драйверов AdrenoTools. ISO, игровые данные и обновления составов в релиз не включены.

## Возможности

- Два режима качества матча: 960 × 540 и 1280 × 720; интерфейс — 1280 × 720. Выбор режима выполняется в лаунчере до запуска игры.
- Переключатели зрителей, трибун с креслами и запасных на скамейке; качество игроков на льду ими не снижается.
- Системный Vulkan-драйвер или установленный пользователем драйвер через AdrenoTools. Переключение драйвера требует перезапуска игры. Есть очистка графического кеша.
- Импорт ZIP обновления состава для выбранного профиля; новые игры и сезоны используют обновление, существующие сохранения не переписываются.
- Настройки управления во время игры через кнопку ⚙ рядом со счётчиком FPS или Select → Настройки. Изменение разрешения рендера во время игры отключено.

## Проверка и ограничения

Импорт указанного ISO целиком проверен пользователем на Lenovo Y700 (`TB321FU`, Android 15). Чтение всех 20 файлов дополнительно проверено на компьютере по SHA-256. Тесты импортера подтверждают сохранность предыдущей установки при ошибке или отмене, а также сохранение кеша и пользовательских данных при успешной замене.

Полное прохождение игры и все комбинации GPU/драйверов не проверены. На отдельных сценах возможны просадки FPS; ранее наблюдались ошибки позы вратаря в повторах. Дополнительный Turnip может работать хуже системного драйвера. Совместимость с Adreno 830 и другими GPU следует оценивать отдельно на устройстве.
